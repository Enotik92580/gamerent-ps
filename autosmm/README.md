# AutoSMM 23.1.1 — что изменилось

## 23.1.1

- **Без «пакетов» по умолчанию.** Автовыгрузка и создание лота больше не поднимают «количество за 1 шт.»
  до минимума услуги: 1 шт. на FunPay = 1 единица услуги. Если у услуги есть минимум, в названии пишется
  «ОТ 10 ШТ», а в описании — «от 10 до … шт.». Пакеты остаются по желанию: «📏 Пакет по минимуму» в мастере.
- **«🛍 Лоты → 📦 Кол-во за 1 шт. всем лотам»** — меняет количество у всех лотов и сразу пересчитывает
  цены и описания на FunPay (исправляет лоты, выставленные пакетами).
- Смена количества или услуги в карточке лота сразу обновляет цену и описание на FunPay.


## 23.1.0

- **Чёткие названия лотов для всех типов услуг.** В название попадает вариант услуги из панели:
  «⭐ ПОДПИСЧИКИ TELEGRAM ⭐ БЕЗ ГАРАНТИИ • РЕЗЕРВНЫЕ», «⭐ ПРОСМОТРЫ TELEGRAM ⭐ ПОСЛЕДНИЕ 5 ПОСТОВ»,
  «⭐ РЕАКЦИИ TELEGRAM ⭐ 👍❤🔥 • ПОЗИТИВНЫЕ». Переключатель в «🎨 Оформление → 🏷 Название»: тип + вариант
  или название услуги из панели целиком. Новая переменная шаблонов `{variant}`.
- **Вотчер сам меняет цену.** Когда провайдер меняет цену услуги, цены лотов с ней сразу пересчитываются
  (если у лота включена «💰 Автоцена»; изменения меньше 0,5% на FunPay не отправляются).
  Настройка «Цена за провайдером» в «⚙️ Настройки».
- **Уведомления вотчера можно приглушить:** режимы «только важные» (по умолчанию — цена от 5%, название,
  лимиты, пропажа услуги), «все», «выключены». Все изменения за проверку приходят одним сообщением,
  в нём есть кнопки «🔕 Только важные» и «🔇 Выключить».
- Исправлено: «Автопросмотры» определялись как голоса в опрос.


## 23.0.1

- Исправлено: FunPay отклонял создание лотов с ошибкой «Составление некорректного английского описания…» —
  в английском описании оставалась команда «чек». Теперь EN-поля всегда без кириллицы, а если FunPay
  всё равно не примет английский текст, лот сохраняется с упрощённым латинским описанием.

## 23.0.0

Плагин для FunPay Cardinal: автопродажа SMM-услуг через панели с API v2.
Файл для установки: `AutoSMM_LuckyFunpay.py` (заменить старый в папке `plugins`, затем `/restart`).

## Обновление со старой версии

- Настройки, лоты, история заказов и ожидающие заказы переносятся автоматически (схема 14).
- Перед первой записью создаётся резервная копия в `storage/cache/autosmm_backups/` (хранятся последние 15).
- Старый прокси `proxies {enabled, url}` переносится как есть: был выключен — режим «напрямую».
- Каждому лоту выдаётся тег `#SMM:xxxxxxxx`, бот сам допишет его в описание лотов на FunPay в фоне.
- **«⏸ Остановить» теперь не теряет заказы**: оплаченные заказы принимаются всегда. Чтобы перестать
  продавать, есть кнопка «🛑 Снять с продажи» (выключает лоты на FunPay и потом возвращает их).

## Исправленные ошибки

| Было | Стало |
|---|---|
| Панель в долларах: лот выставлялся по цене в $ как в ₽, а заказы уходили на возврат | Курс ЦБ РФ или ручной, валюта панели определяется автоматически |
| Автовыгрузка не учитывала min/max услуги, остаток всегда 99999 | Количество подгоняется под минимум, остаток = max ÷ количество, отчёт о пропусках |
| Лот искался по части названия, заказ молча пропускался | Тег `#SMM` → точное название → название + параметры; при неоднозначности приходит уведомление |
| Ссылка уходила в последний заказ покупателя | Очередь заказов: по одному, с сообщениями «в очереди» и «следующий заказ» |
| Фоновые процессы стартовали до входа в аккаунт | Запуск после полной загрузки (POST_INIT) |
| Запросы к панели блокировали Cardinal | Сетевые операции выполняются в фоновых потоках |
| Гонки потоков, битый JSON стирал настройки и историю | Транзакции, блокировки, бэкапы, восстановление, защита от записи пустых лотов |
| Возврат по антидемпингу без уведомления | Уведомление с ценой и себестоимостью; при отсутствии цены заказ не возвращается |
| Дубли при повторной выгрузке | Уже выставленные услуги пропускаются |
| Ранний «выполнено» от панели | Защитный период (5 мин, для smmbind — 15 мин и двойная проверка) |
| Спам «Пришлите ссылку» на каждое сообщение | Подсказка не чаще раза в 10 минут; понимает `t.me/x`, `@channel`, «да/ок» |

## Новые возможности

- **Лоты:** поиск, листание, фильтры, полная карточка с правкой всех полей, вкл/выкл на FunPay,
  цена и остаток, удаление с подтверждением (по желанию и с FunPay).
- **➕ Новый лот:** привязка по FunPay ID или создание из услуги панели с предпросмотром, правкой
  названия и цены, выбором полей раздела.
- **📦 Автовыгрузка 2.0:** группировка по категориям или соцсетям, выбор услуг галочками, фильтр,
  карта разделов FunPay, пример лота, остановка, откат выгрузки.
- **🎨 Оформление:** 22 соцсети × 23 типа услуг, 6 тем, разбор названий панели (скорость, старт, гарантия),
  нормальный английский текст, свои шаблоны с переменными, назначения «соцсеть + тип → шаблон»,
  переоформление уже выставленных лотов.
- **💰 Автоцена**, **🔴 защита от низкого баланса**, **👁 вотчер изменений услуг**, **♻️ рефилл**,
  **🔢 опросы**, **⏸ /stop и /start** в чате с покупателем, **🌐 прокси** для каждой панели,
  чёрный список Cardinal, напоминания о ссылке, расширенная статистика.

## Команды

- `/auto_smm_settings` — меню плагина;
- `/start_smm`, `/stop_smm` — запуск/остановка фоновых процессов;
- в чате FunPay (продавец): `/stop`, `/start`;
- покупатель: `чек НОМЕР`, `!рефилл` (`!refill`, `рефилл`, `/рефилл`).
