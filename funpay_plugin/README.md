# Auto VIP Roblox v17 — плагин для FunPay Cardinal

Плагин сдаёт VIP-серверы Roblox в аренду на FunPay и работает так, как описано в руководстве
«🎮 Руководство по плагину Auto VIP Roblox». Вся настройка делается в Telegram: `/vip_config`
или кнопка настроек в карточке плагина.

## Установка и обновление

1. Остановите Cardinal. Сохраните копию старого `.py` и файла `AutoVIPRoblox_Monolith.db`.
2. Положите `AutoVipRoblox_LuckyFunpay.py` в папку `plugins`, а старую версию плагина уберите
   оттуда (UUID у них одинаковый).
3. Запустите Cardinal и включите плагин: `/menu` → Система и конфиги → Плагины → Auto VIP Roblox →
   Включить. Затем выполните `/restart`.
4. Откройте `/vip_config`.

При первом запуске плагин создаёт новую базу `AutoVIPRoblox_v17.db`. В неё он переносит данные
из старой `AutoVIPRoblox_Monolith.db` (v11/v15/v16):

- аккаунты, категории, серверы, лоты, цены, бонусы и настройки;
- активные аренды с добавленными друзьями;
- историю и сумму заработка;
- уже обработанные заказы и выданные бонусы за отзыв.

Старая база не изменяется и остаётся резервной копией. Итог переноса бот присылает в Telegram.

Шаблоны сообщений из прошлой версии переносятся, только если в них нет устаревших переменных
(`{owner_url}`, `{bonus_line}`). В остальных случаях используются новые стандартные тексты.

## Что изменилось по сравнению с v16.2

| Было в v16 | Стало (по руководству) |
|---|---|
| Лот заказа определялся по ID предложения, которого FunPayAPI почти никогда не передаёт, поэтому заказы застревали в «Разборе» | Лот находится по названию, которое входит в описание заказа: сначала полное совпадение, затем самое длинное. Одинаковые названия запрещены, а «🔄 Обновить название с FunPay» перечитывает название |
| Выдача и очистка требовали, чтобы сервер был виден в списке `private-servers`. Иначе — бесконечный `cleanup_failed` | Владелец сервера определяется через `GET /vip-servers/{id}` с перебором всех аккаунтов. Аренда завершается после подтверждённого выключения сервера, ссылка сбрасывается |
| Повторная покупка продлевала аренду | Каждая покупка — отдельная аренда со своим сервером и таймером. Продление — только кнопкой 🔄 Продлить |
| Выбор аренды через `#ЗАКАЗ` | Нумерованный список, ответ номером, «отмена/cancel/стоп», выбор действует 5 минут. `!время` показывает все аренды |
| Блокировка заказов держалась во время запросов к Roblox | Заказы обрабатываются по очереди в отдельном потоке, Telegram и Cardinal не зависают |
| Новый лот создавался «на паузе» и сразу выключался на FunPay | Новый лот работает в режиме «Рандом», цены по умолчанию 50/100 |
| Команды срабатывали на фразы без «!» («друзья мои…») | Только `!команды`/`!help`, `!время`, `!ссылка`, `!друзья`, `!бронь`, `!отзыв` |
| Не было | Предупреждение за 15 минут, уведомление «🏁 Аренда завершена», «🤫 Тихо завершить», платное добавление в друзья (временные лоты `#FRXXXXX`), проверка чёрного списка, отдельное сообщение-приглашение |
| Бонусы умножались, порог — наибольший, отзыв только 5★ | Первое подходящее правило без умножения, переключатель бонусов. Отзыв засчитывается с любой оценкой, `{new_time}` работает |
| Ошибка в шаблоне ломала сообщение | Неизвестная переменная или лишняя скобка — бот отправляет упрощённый стандартный текст |

Есть несколько намеренных отличий от руководства, они защищают от поломок:

- Аккаунт или сервер с активной арендой удалить нельзя: бот объясняет причину.
- Если Roblox не подтвердил выключение сервера, аренда остаётся в статусе «завершается». Сервер
  не продаётся повторно, бот сам повторяет попытки и уведомляет администратора. В карточке аренды
  есть кнопка «🔁 Повторить сейчас».
- Кнопку в карточке плагина рисует сам Cardinal, поэтому она называется «⚙️ Настройки», а не
  «🎮 Панель Roblox». Открывает она ту же панель.

## Проверка

```bash
python3 -m unittest discover -s funpay_plugin/tests -v
```

Тесты имитируют Cardinal, FunPayAPI, Telegram и Roblox и проходят сценарии руководства:

- настройку через панель;
- покупку и повторную покупку;
- выбор сервера в чате;
- друзей, лимиты и платное добавление;
- таймеры: предупреждение, окончание, продление;
- бонусы и шаблоны;
- автовозврат и ошибку генерации ссылки;
- режим цен и автоуправление лотами;
- повтор очистки;
- перенос базы v16.

Реальные ответы Roblox и FunPay (создание временного лота, отключение игроков) нужно проверить
на своём аккаунте проверочной покупкой.
